# MEGA
☁️ MEGA – Cloud File Storage Website

» A responsive static website that presents a cloud storage service where users can upload, store, and access their files in the cloud. Built entirely with **HTML5** and **CSS3** as a hands-on learning project.

---
📌 About the Project

» This project is a front-end static website that demonstrates the interface of a cloud storage platform. Users can upload their files and save them to the cloud through a clean, easy-to-use layout.

» I built this project to put everything I have learned in web development into practice, applying real HTML and CSS concepts from start to finish.

---
🛠️ Technologies Used

| **HTML5** | Structure and semantic content of the website |
| **CSS3** | Styling, layout, colors, and design |

 » CSS Techniques Used

- **Inline CSS** – styling applied directly on elements using the `style` attribute
- **Internal CSS** – styles written inside the `<style>` tag in the HTML file
- **External CSS** – styles kept in a separate `.css` file and linked with `<link>`

---
📚 Concepts Applied

» While developing this website, I applied the HTML and CSS concepts I have learned so far, including:

- Commonly used HTML5 tags and their attributes
- Semantic elements such as `<header>`, `<nav>`, `<section>`, and `<footer>`
- Forms, input fields, buttons, links, images, lists, and tables
- CSS selectors (element, class, ID), colors, fonts, spacing, and the box model
- Layout styling and design best practices
- Proper file and folder organization

---
🎯 Learning Outcome

» Through this project, I gained hands-on experience in:

- Building a complete multi-page static website from scratch
- Using internal, external, and inline CSS together
- Writing clean and organized HTML5 code
- Understanding how real websites are structured and styled
